# 资料提供方的格式

`/race/controls.html` 是赛务公告。表中给赛段号、物理管制点、关闭时间段和公告修订。所有分钟是当地分钟，限制区间左闭右开。`/gates.json` 含有向路段及通过所需分钟，class 判断 allowed 分类和例外，live 是通行点实报的计划版本、通行方向与有效区间，live 的行依次为路口、方向、起止分钟、所依据公告修订、现场状态和该区间放行车辆数。门岗额度按整个窗口计。`/stores.json` 是到店请求、时窗及装卸分钟，各承运车辆预约彼此独立。
`/passes` 为网页票据查询，接受票号、路口和查询轮次，对同一点不同方向会显示各自许可状态及已经通过时间。
`/apply` 是通行票申领网页。待复核和受理均可获得票据编号，实际通行从回读页核验。
